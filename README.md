## 🏗️ Build and run

In your project root, run:

mvn clean package


Then run either:

java -jar target/CreateWhiteBoard.jar  <serverPort> <username>


or

java -jar target/JoinWhiteBoard.jar <serverIPAddress> <serverPort>
